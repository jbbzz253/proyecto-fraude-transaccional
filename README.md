# Monitoreo y Prevención de Fraude Transaccional

Pipeline analítico integral y evaluación comparativa entre un sistema tradicional de reglas de negocio, un modelo predictivo de Machine Learning y una estrategia de decisión híbrida sobre más de 16,000 transacciones financieras.

## 📌 Benchmark de Estrategias

| Estrategia | Alertas Emitidas | Precisión / Efectividad | Monto Prevenido |
| :--- | :---: | :---: | :---: |
| **Reglas** | 499 | 4.61 % | S/ 23,154.74 |
| **Modelo Predictivo** | 529 | 4.16 % | S/ 29,181.16 |
| **Híbrida (Recomendada)** | **464** | **4.96 %** | **S/ 23,154.74** |

> **Conclusión:** La estrategia híbrida optimizó la carga operativa reduciendo las alertas a 464 casos y maximizó la tasa de precisión al 4.96%, superando el desempeño aislado de reglas y modelo.

## 🛠️ Stack Tecnológico
- **Modelado & Pipeline:** Python (Pandas, Scikit-Learn)
- **Consultas & Exploración:** SQL / Relational DB
- **Visualización & BI:** Power BI Desktop
